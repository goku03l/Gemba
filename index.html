How auto-refresh works

A scheduled job runs on GitHub every day — no tap, no open app required. It searches the web with a key that's stored as a secret, never in this page, saves results into this site's data file, and the site redeploys itself automatically.

To change what it searches for: edit data/queries.json in the GitHub repo — one query per line, no code needed.

To get a Telegram ping the moment new events are found: message @BotFather on Telegram, create a bot, then add its token and your chat ID as repo secrets (TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID). Ask Claude if you want the exact steps.

This feed refreshes once a day. "Check for updates" below just re-reads today's file — it doesn't run a new search itself.
